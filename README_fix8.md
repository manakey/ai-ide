## fix8 の修正内容

### 1. タブ切り替えでAIチャットがリセットされる問題を修正
- **原因**: タブ切り替え時に React がコンポーネントをアンマウント → 会話履歴が消える
- **修正**: 全パネル（エディタ/チャット/実行/ターミナル）を常にマウントしたまま、
  `display: none` スタイルで表示/非表示を切り替えるように変更
- チャットの会話履歴、エディタの状態、ターミナルの接続がすべて保持される

### 2. ブラウザ用JSコードを Node.js で実行してエラーになる問題を修正
- **原因**: `document.getElementById()` など DOM API を使うコードを Node.js で実行
- **修正1 (バックエンド code.js)**: JS コードに `document`/`window`/`canvas` などが含まれる場合、
  Node.js で実行せず HTML ラッパーでブラウザプレビューに切り替え
- **修正2 (フロントエンド App.jsx)**: `.html` 拡張子のファイルは API を呼ばず、
  内容を直接 iframe でプレビュー（即座、高速）
